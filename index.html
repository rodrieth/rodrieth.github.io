🛡️ System Requirements

Verzeta-Studio is designed to be lightweight and efficient. Here's what you need:

  • Operating System: Windows 10 or Windows 11 (64-bit)
  • Processor: Any modern multi-core processor (Intel i5 or AMD Ryzen 5 or better recommended)
  • Memory: At least 8GB RAM (16GB+ recommended for running multiple AI models)
  • Storage: The app takes about 500MB, but AI models can take 2-10GB each
  • GPU: Optional, but a graphics card with 6GB+ VRAM will speed up AI processing significantly

💡 No technical knowledge needed

You don't need to know anything about programming, AI, or software development to use Verzeta-Studio. If you can use a chat app, you can use this. The installation is just like installing any Windows program.

🔧 Troubleshooting - Common Issues

❌ "Windows protected your PC" warning

Because Verzeta-Studio is open source and not sold commercially, Windows SmartScreen may show a warning. Click "More Info" and then "Run Anyway". This message disappears after the first launch.

❌ Application won't start

Make sure you have the latest version of Windows Update installed. If the issue persists, restart your computer and try again. Most startup issues are resolved this way.

❌ AI models not loading

This usually means you need more storage space. AI models require several gigabytes. Clear out old downloads or move them to another drive. Check your internet connection - the models need to download once before going local.
